# Icons

PNG icons at 16, 32, 48, and 128 pixels, generated from the career-ops.org mark.
`source-180.png` is the original 180x180 source; the numbered files are resized
from it and are what `manifest.json`, `manifest.firefox.json`, and the build
(`esbuild.mjs`) reference. Regenerate the numbered files from a fresh source
export rather than hand-editing them.
